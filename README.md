# 🚀 LootSync — Sistema de Gestão de Catálogo e Versões

> Sistema backend e painel de controle desenvolvido para gerenciamento de ativos digitais, builds, sprites e recursos para desenvolvimento de jogos indie e streamings.

## 🛠️ Tecnologias Utilizadas
* **Python** (com **FastAPI**) para a construção da API de alta performance.
* **SQLAlchemy** + **SQLite** para a persistência e modelagem relacional dos dados.
* **HTML5, CSS3 e JavaScript** para o painel de controle web (Dark Mode / Tema SyncedCorp).
* **Pydantic** para validação robusta de dados.

## 📌 Funcionalidades da API (CRUD Completo)
* **CREATE:** Cadastro de novos assets com nome, tipo, versão, tamanho e descrição.
* **READ:** Listagem completa de todos os produtos do catálogo.
* **UPDATE:** Atualização de dados de assets existentes via ID.
* **DELETE:** Remoção de itens do banco de dados.
